# Paper ID and Bibliographic Record Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Identify every opened PDF by a Paper ID (DOI, else arXiv ID, else Zotero item key, else File Fingerprint), look up its Bibliographic Record from CrossRef or arXiv, and keep Chat History and the translation glossary per Paper ID instead of per file.

**Architecture:** `app/paper_id.py` reads identifiers from a PDF's metadata and first two pages and builds a Paper ID string. `app/biblio.py` fetches title, authors, and year for `doi:` and `arxiv:` Paper IDs and checks that the record's title actually appears on the PDF's first page, which rejects a DOI picked up from a citation. `app/store.py` gains a small Paper registry and re-keys Chat History by Paper ID, migrating chats saved per `doc_id`. `app/main.py` identifies a paper when it is ingested and uses the Paper ID for chat, the glossary, and the library title. Layout, translation, summary, anatomy, and equation caches stay keyed by `doc_id`, which is already the File Fingerprint.

**Tech Stack:** Python 3.12, PyMuPDF (`pymupdf`), stdlib `urllib` + `xml.etree` for CrossRef/arXiv, FastAPI, vanilla JS, `unittest`.

**Spec:** `docs/adr/0001-paper-id-separate-from-file-fingerprint.md`, `GLOSSARY.md` (Paper, Paper ID, File Fingerprint, Bibliographic Record, Chat History), and grilling decisions Q6 (Chat History stored under `data/`), Q7 (two identities), Q13 (look up the record online, fall back to the PDF title).

## Global Constraints

- Paper ID priority: DOI, else arXiv ID, else Zotero item key, else File Fingerprint. Forms: `doi:<lowercased doi>`, `arxiv:<id without version>`, `zotero:<item key>`, `file:<doc_id>`.
- A DOI of the form `10.48550/arXiv.<id>` is an arXiv ID, so it becomes `arxiv:<id>`.
- arXiv versions share one Paper ID (`2506.09762v1` and `2506.09762v2` are both `arxiv:2506.09762`).
- When the Paper was opened from Zotero, Zotero's stored DOI wins over a DOI read from the PDF.
- Layout, translation, summary, anatomy, and equation caches stay keyed by `doc_id` (the File Fingerprint). Chat History and the translation glossary are keyed by Paper ID.
- Network: only the DOI or arXiv ID is sent, only to `api.crossref.org` and `export.arxiv.org`, with no email address or other user data. Each request times out after 6 s. Failures are never fatal and are not cached, so the next open retries.
- No new dependencies.
- Zotero integration itself is out of scope; this plan only accepts an optional `{"key", "doi"}` for it.
- Tests use `unittest`, never touch the network, and never read the developer's `data/`.
- Before every commit run `uvx ruff format . && uvx ruff check --fix .`.

## Review Focus

- **A DOI on the first page belongs to a cited work, not this paper:** the paper must not inherit another paper's title or chat. Test in Task 2 (`test_title_matches_rejects_unrelated_title`) and Task 4 (`test_doi_from_a_citation_is_rejected`).
- **No internet or CrossRef down when opening a paper:** the paper opens promptly with the PDF's own title, and a later online open fills in the record. Test in Task 4 (`test_offline_open_uses_pdf_title_then_fills_record_later`).
- **Chats saved before this change (per `doc_id`):** they still appear after upgrading. Test in Task 3 (`test_chat_migrates_from_doc_id`) and Task 4 (`test_legacy_doc_chat_still_visible`).
- **Two different PDF files of the same paper (annotated copy, v1/v2 of an arXiv preprint):** they share one Chat History but keep separate translation caches. Test in Task 1 (`test_arxiv_versions_share_one_id`) and Task 4 (`test_two_files_of_one_paper_share_chat`).
- **DOIs with characters unsafe for filenames (`/`, `<`, `(`, `;`):** storage never breaks or escapes `data/`. Test in Task 3 (`test_unsafe_paper_ids_map_to_safe_files`).

def make_pdf(pages: list[str], metadata: dict | None = None) -> bytes:
    doc = pymupdf.open()
    for text in pages:
        page = doc.new_page(width=595, height=842)

    data = doc.tobytes()
    doc.close()
    return data

`app/paper_id.py`:

```python
"""Paper ID: which scholarly work a PDF holds (ADR 0001).

Priority: DOI, else arXiv ID, else Zotero item key, else the File Fingerprint (doc_id).
Identifiers come from the PDF metadata and the first two pages only, because later pages
are full of cited works' DOIs."""

from __future__ import annotations

import re

import pymupdf

_DOI = re.compile(r"\b(10\.\d{4,9}/[^\s\"<>]+)", re.I)
_ARXIV = re.compile(r"arxiv(?:\.org/abs/|:)\s*(\d{4}\.\d{4,5})(?:v\d+)?", re.I)
_ARXIV_DOI = re.compile(r"10\.48550/arxiv\.(\d{4}\.\d{4,5})", re.I)


def _clean_doi(doi: str) -> str:
    return doi.rstrip(".,;:)]}'\"").lower()


def identifiers(pdf_bytes: bytes) -> dict:
    doc = pymupdf.open(stream=pdf_bytes, filetype="pdf")
    try:
        meta = " ".join(str(v) for v in (doc.metadata or {}).values() if v)
        pages = [doc[i].get_text() for i in range(min(2, len(doc)))]
    finally:
        doc.close()
    doi = None
    for text in (meta, *pages):
        m = _DOI.search(text)
        if m:
            doi = _clean_doi(m.group(1))
            break
    arxiv = None
    for text in (meta, *pages):
        m = _ARXIV.search(text)
        if m:
            arxiv = m.group(1)
            break
    return {"doi": doi, "arxiv": arxiv}


def paper_id(
    *,
    fingerprint: str,
    doi: str | None = None,
    arxiv: str | None = None,
    zotero_key: str | None = None,
) -> str:
    if doi:
        m = _ARXIV_DOI.fullmatch(doi)
        return f"arxiv:{m.group(1)}" if m else f"doi:{doi.lower()}"
    if arxiv:
        return f"arxiv:{arxiv}"
    if zotero_key:
        return f"zotero:{zotero_key}"
    return f"file:{fingerprint}"
```

`app/biblio.py`:

```python
"""Bibliographic Record lookup for doi:/arxiv: Paper IDs (CrossRef, arXiv).

Only the identifier is sent; no user data. Failures return None and are not cached by the
caller, so the next open retries."""

from __future__ import annotations

import asyncio
import json
import re
import urllib.parse
import urllib.request
import xml.etree.ElementTree as ET

TIMEOUT_S = 6
_UA = "paper-reader (local research paper reader)"
_ATOM = "{http://www.w3.org/2005/Atom}"


def _get(url: str) -> bytes:
    req = urllib.request.Request(url, headers={"User-Agent": _UA})
    with urllib.request.urlopen(req, timeout=TIMEOUT_S) as resp:
        return resp.read()


def _squash(text: str) -> str:
    return " ".join((text or "").split())


def _crossref(doi: str) -> dict:
    msg = json.loads(
        _get("https://api.crossref.org/works/" + urllib.parse.quote(doi, safe="/"))
    )["message"]
    authors = [
        _squash(f"{a.get('given', '')} {a.get('family', '')}")
        for a in msg.get("author", [])
    ]
    parts = (msg.get("issued") or {}).get("date-parts") or [[None]]
    return {
        "title": _squash((msg.get("title") or [""])[0]),
        "authors": [a for a in authors if a],
        "year": parts[0][0],
        "source": "crossref",
    }


def _arxiv(aid: str) -> dict:
    root = ET.fromstring(
        _get("https://export.arxiv.org/api/query?id_list=" + urllib.parse.quote(aid))
    )
    entry = root.find(f"{_ATOM}entry")
    if entry is None:
        raise ValueError("arXiv returned no entry")
    published = entry.findtext(f"{_ATOM}published") or ""
    return {
        "title": _squash(entry.findtext(f"{_ATOM}title") or ""),
        "authors": [
            _squash(a.findtext(f"{_ATOM}name") or "")
            for a in entry.findall(f"{_ATOM}author")
        ],
        "year": int(published[:4]) if published[:4].isdigit() else None,
        "source": "arxiv",
    }


async def lookup(pid: str) -> dict | None:
    scheme, _, value = pid.partition(":")
    fetch = {"doi": _crossref, "arxiv": _arxiv}.get(scheme)
    if fetch is None or not value:
        return None
    try:
        record = await asyncio.to_thread(fetch, value)
    except (OSError, ValueError, KeyError, IndexError, TypeError, ET.ParseError):
        return None
    return record if record["title"] else None


def _words(text: str) -> list[str]:
    return [w for w in re.findall(r"[a-z0-9]+", (text or "").lower()) if len(w) > 2]


def title_matches(title: str, page_text: str) -> bool:
    """True when most of the record's title words appear on the PDF's first page. A DOI read
    from the PDF can belong to a cited work; its title will not be on this first page."""
    words = _words(title)
    if not words:
        return False
    page = set(_words(page_text))
    return sum(w in page for w in words) / len(words) >= 0.6


def byline(record: dict | None) -> str:
    if not record:
        return ""
    authors = record.get("authors") or []
    who = f"{authors[0]} et al." if len(authors) > 2 else ", ".join(authors)
    year = record.get("year")
    return f"{who} ({year})" if who and year else who or (str(year) if year else "")
```

```python
def _key(pid: str) -> str:
    """Filesystem-safe name for a Paper ID (DOIs may contain '/', '<', ';', ...)."""
    return hashlib.sha256(pid.encode("utf-8")).hexdigest()[:16]


def paper_get(pid: str) -> dict | None:
    try:
        return json.loads((PAPERS / f"{_key(pid)}.json").read_text("utf-8"))
    except (OSError, ValueError):
        return None


def paper_put(pid: str, record: dict) -> None:
    PAPERS.mkdir(parents=True, exist_ok=True)
    (PAPERS / f"{_key(pid)}.json").write_text(
        json.dumps({"paper_id": pid, **record}, ensure_ascii=False), "utf-8"
    )


def paper_cache_id(pid: str) -> str:
    """A cache_get/cache_put id for caches that belong to the Paper, not to one PDF file."""
    return f"paper_{_key(pid)}"


def chat_get(pid: str) -> list[dict]:
    try:
        turns = json.loads((CHATS / f"{_key(pid)}.json").read_text("utf-8"))
    except (OSError, ValueError):
        return []
    return turns if isinstance(turns, list) else []


def chat_put(pid: str, turns: list[dict]) -> None:
    CHATS.mkdir(parents=True, exist_ok=True)
    (CHATS / f"{_key(pid)}.json").write_text(
        json.dumps(turns, ensure_ascii=False), "utf-8"
    )


def chat_clear(pid: str) -> None:
    (CHATS / f"{_key(pid)}.json").unlink(missing_ok=True)


def chat_migrate(doc_id: str, pid: str) -> None:
    """Move a chat saved per doc_id (before Paper IDs) to its Paper, never overwriting."""
    old = CHATS / f"{doc_id}.json"
    new = CHATS / f"{_key(pid)}.json"
    if old.exists() and old != new and not new.exists():
        old.replace(new)
```

async def _ingest(data: bytes, zotero: dict | None = None) -> dict:
    """Store + extract a PDF (idempotent by content hash), then identify its Paper.
    Returns summary meta. `zotero` = {"key", "doi"} when opened from Zotero."""
    doc_id = store.doc_id_for(data)
    extracted = store.load_doc(doc_id)
    if extracted is None:
        extracted = pdf_utils.extract(data)  # may raise; caller converts to HTTP error
        store.save_pdf(doc_id, data)
        store.save_doc(doc_id, extracted)
    pid = extracted["meta"].get("paper_id")
    unresolved = (
        pid and pid.split(":")[0] in ("doi", "arxiv") and store.paper_get(pid) is None
    )
    if pid is None or zotero or unresolved:

    record = store.paper_get(pid)
    return {
        "doc_id": doc_id,
        "paper_id": pid,

        "byline": biblio.byline(record),

async def _identify(doc_id: str, data: bytes, extracted: dict, zotero: dict) -> str:
    """Pick the Paper ID (ADR 0001) and fetch its Bibliographic Record when possible."""
    found = paper_id.identifiers(data)
    doi = zotero.get("doi") or found["doi"]
    pid = paper_id.paper_id(
        fingerprint=doc_id, doi=doi, arxiv=found["arxiv"], zotero_key=zotero.get("key")
    )
    if store.paper_get(pid) is None and pid.split(":")[0] in ("doi", "arxiv"):
        record = await biblio.lookup(pid)
        first_page = extracted["pages"][0] if extracted["pages"] else ""
        if record and (
            zotero.get("doi") or biblio.title_matches(record["title"], first_page)
        ):
            store.paper_put(pid, record)
        elif record:
            # The identifier read from the PDF names another work (e.g. a citation).
            pid = paper_id.paper_id(fingerprint=doc_id, zotero_key=zotero.get("key"))
    extracted["meta"]["paper_id"] = pid
    store.save_doc(doc_id, extracted)
    store.chat_migrate(doc_id, pid)
    return pid


def _paper_of(doc_id: str, doc: dict) -> str:
    """Paper ID for a stored doc; docs ingested before Paper IDs use their fingerprint."""
    pid = doc["meta"].get("paper_id") or f"file:{doc_id}"
    store.chat_migrate(doc_id, pid)
    return pid
