이미 쓰는 AI 구독으로 시작하세요. 논문과 읽던 기록을 내 컴퓨터에 모아두세요.

구독별 사용량 제한이 적용됩니다. AI 기능을 사용하면 논문 내용이 선택한 AI 제공자에게 전송됩니다. Sundark는 개인용 로컬 앱입니다.

시작하기

다음 논문은
Sundark에서.

macOS 기준 · Python 3.10+ 및 uv 필요

전체 설치 안내 보기

  1. 프로젝트를 내려받으세요

    git clone https://github.com/jmy-org/sundark.git
cd sundark

  2. 설치하고 실행하세요

    uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8743

    레이아웃 모델을 포함해 macOS에서 약 1 GB를 설치합니다. 첫 실행 시 모델 파일이 추가로 다운로드됩니다.

  3. 브라우저에서 열고 AI를 연결하세요

    http://127.0.0.1:8743에 접속한 뒤 AI 설정에서 로그인하세요. PDF를 열면 읽을 준비가 끝납니다.

시작하기 전에

이 웹사이트에서 바로 논문을 읽을 수 있나요?

이곳은 제품 소개 페이지입니다. 실제 리더는 설치 후 내 컴퓨터에서 실행합니다. 공개 서버 운영을 위한 접근 제어는 제공하지 않습니다.

스캔한 논문도 지원하나요?

현재는 텍스트가 포함된 PDF를 지원합니다. 스캔한 이미지 PDF를 위한 OCR은 지원하지 않습니다.

AI 구독만 있으면 되나요?

선택한 도구의 설치와 로그인, 계정의 모델 사용 권한이 필요합니다. ChatGPT는 별도 CLI 없이 앱에서 연결할 수 있습니다. 지원 여부와 사용량 제한은 계정과 제공자에 따라 다릅니다.
